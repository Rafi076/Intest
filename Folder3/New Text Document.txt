					advanced-workflows


		Functionality				Commands to practice

		Discard unstaged changes		git restore file.txt

		Unstage a file				git restore --staged file.txt

		Undo a commit safely			git revert COMMIT_ID

		Reset to an earlier commit		git reset --soft HEAD~1

		Reset staging and working tree		git reset --hard HEAD~1

		Save unfinished work			git stash

		List saved work				git stash list

		Restore saved work			git stash pop

		Reapply a commit			git cherry-pick COMMIT_ID

		Rebase a branch				git rebase main

		Create a version tag			git tag v1.0.0

		Push tags				git push origin --tags

		Find a commit that introduced a bug	git bisect

		Inspect file history			git blame file.txt

		Clean untracked files			git clean -n
